Description

xcsh is an AI-powered assistant for F5 Distributed Cloud, delivered as an Office task-pane add-in. It requires the xcsh CLI installed and running locally on your computer.

Requirements

xcsh requires: (1) the xcsh CLI installed via Homebrew (brew install f5-sales-demo/tap/xcsh), (2) a running local server (xcsh office serve), and (3) a compatible version of Microsoft Excel, Word, or PowerPoint.
